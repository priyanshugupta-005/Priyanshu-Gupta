# Priyanshu's Personal Portfolio Website 🚀
**B.Tech First Year Student | JECRC University**

A high-performance personal portfolio website built with modern HTML5, CSS3, and an interactive **Three.js 3D Background**. Designed specifically for submission to your professor and showcasing academic progress, technical skills, and extracurricular accomplishments.

---

## 🌟 Key Features

1. **Interactive 3D Background**:
   - Built using **Three.js**.
   - Features glowing particle constellations and floating 3D polyhedra (icosahedrons, octahedrons, toruses) that react in real-time to mouse movement and window scrolling.
2. **Clean & Simple Logo**:
   - Modern geometric monogram `[ P ]` with glowing cyber accents.
3. **Structured Portfolio Sections**:
   - **Hero Section**: Dynamic introduction, age, student badge, university affiliation, and quick overview card.
   - **About Me**: Complete profile details (Name: Priyanshu, Age: 18, DOB: 05/12/2007, JECRC University).
   - **Education Journey**: Interactive timeline for B.Tech 1st Year, Class 12th (Qualified), and Class 10th (Qualified).
   - **Skills**: Dual-column layout displaying programming (Java, Python) and explorer qualities (Travelling, Exploring New Things).
   - **Achievements**: Detailed milestone cards for Java & Python programming, School-Level Badminton, and School-Level Chess.
   - **Contact & Feedback**: Functional feedback form and institutional contact details formatted for your professor's review.

## 🚀 How to Open & Present

You do **not** need to install Node.js or any complex dependencies.

### Option 1: Direct Browser Launch
1. Navigate to the folder: `C:\Users\priya\.gemini\antigravity\scratch\priyanshu-portfolio`
2. Double-click **`index.html`** to open it in Chrome, Edge, Brave, or Firefox.

### Option 2: Run a Local Server (Recommended for Professor Demo)
If Python is installed on your computer, open PowerShell in the project directory and run:
```powershell
python -m http.server 8000
```
Then visit **`http://localhost:8000`** in your browser.
